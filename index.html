Cómo publicar archivos en GitHub

Procedimiento para que los documentos se muestren automáticamente.

  1. Configura el repositorio

    Edita las variables GITHUB_USER y GITHUB_REPO al inicio del JavaScript. En GitHub Pages normalmente también se detectan automáticamente desde la URL.

  2. Conserva las carpetas exactas

    Usa /Unidad_I para la primera unidad y /Unidad_II para la segunda. GitHub distingue mayúsculas, minúsculas y guiones bajos.

  3. Sube los documentos

    Entra a la carpeta correspondiente, pulsa Add file → Upload files, selecciona los archivos y confirma el commit.

  4. Verifica GitHub Pages

    Cuando termine el despliegue, pulsa “Actualizar lista”. La API pública detectará todos los archivos de ambas carpetas, incluso los nuevos.

const GITHUB_USER = "tu-usuario"; const GITHUB_REPO = "tu-repositorio"; const GITHUB_BRANCH = "main";
Seguridad: no coloques tokens personales de GitHub en este archivo. Al ser una página pública, cualquier clave incluida en JavaScript quedaría expuesta.
